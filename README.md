# Student Task Management System

## Project Description
A simple web application that allows students to add, display, complete, delete and search tasks. Built to demonstrate a real collaborative Git and GitHub workflow.

## Team Members
- Mahrukh (GitHub: @mahrukhsaeed2702)
- Sania  (GitHub: @saniakhalid1)

## Features
- Add tasks with a title and description
- Display tasks as cards
- Mark tasks as completed (and undo)
- Delete tasks
- Search tasks by title or description
- Responsive layout for mobile screens

## Technologies
HTML5, CSS3, JavaScript, Git, GitHub

## Git Workflow
Feature-branch workflow: each feature is developed on its own branch, pushed to GitHub, reviewed through a Pull Request, and merged into `main`. Issues are linked to PRs with "Closes #n".

## Branches
- `main` – stable code
- `feature/task-form` – task input form (Mahrukh)
- `feature/task-style` – styling and responsive layout (Sania)
- `docs/readme-sania`, `docs/readme-mahrukh` – README merge conflict demonstration
- `feature/task-complete` – create, delete and complete tasks (Sania)
- `feature/task-search` – task search (Mahrukh)

## Git Commands Demonstrated
init, status, add, commit, log, branch, switch, diff, diff --staged, clone, remote, push, fetch, pull, merge, stash, restore, reset, revert, show, blame, tag

## GitHub Features Demonstrated
Repository, collaborators, branches, issues, pull requests, code reviews, merge, issue linking (Closes #n), tags, releases

## How to Run
1. Clone the repository: `git clone https://github.com/<owner>/student-task-manager.git`
2. Open the folder and double-click `index.html` in a browser.
